# Суть проекта

Перевод заявок на закупку с объектов ГК «Триумф» из PDF в Excel и разбивка позиций по менеджерам отдела снабжения ТД «Дикес».

# Как запускать

**Основной способ — скилл `/zayavki`** (или просьба «обработать новые заявки», «прогнать заявки», «перевести и разложить заявки»). Скилл сам:
1. находит новые PDF в `data/` — те, которых ещё нет в журнале обработки (если пользователь назвал конкретные PDF — берёт только их, даже повторно);
2. переводит их в Excel агентом `zayavki-pdf-to-excel`;
3. дописывает журнал;
4. раскладывает только что созданные заявки по менеджерам агентом `zayavki-po-menedzheram`;
5. выдаёт один общий отчёт.

Агенты по отдельности — только когда пользователь просит конкретный шаг:
- **`zayavki-pdf-to-excel`** — PDF → Excel. На каждый PDF отдельный xlsx в `reports/Заявки готовые/` (лист «Заявка» + лист «Проблемы»). Счета, договоры, сверки, прайсы, КП не обрабатывает — пропускает и называет в отчёте.
- **`zayavki-po-menedzheram`** — готовый xlsx → файлы по менеджерам в `reports/Заявки по менеджерам/Заявка <N> <объект>/<Фамилия Имя>.xlsx`. Работает только по заявкам, которые назвал пользователь; не назвал — уточнить.

Агентам всегда передавать явный список файлов, а не всю папку.

# Журнал обработки

`reports/Заявки готовые/Журнал обработки.csv` — какой PDF в какой xlsx превратился и когда. Разделитель `;`, UTF-8 с BOM. Колонки: `PDF;Готовая заявка;Дата обработки`.
- По журналу определяется, какие PDF новые. Нет файла — создаётся с шапкой.
- PDF, оказавшиеся не заявками, заносятся с пометкой `не заявка` — чтобы больше не трогать.
- PDF, по которым Excel не получился, в журнал не заносятся — при следующем запуске попадут в новые.
- Нужна повторная обработка — назвать PDF явно, журнал для него игнорируется.

# Распределение по менеджерам

Строго по файлу `docs/Отдел снабжения 17.06.2026.xlsx` (лист «Отдел снабжения»). Других источников распределения не использовать, ответственных по памяти не назначать. Файл обновится — работать по новой версии (и поправить имя файла в агенте `zayavki-po-menedzheram`).

# Структура проекта

```
.claude/     служебная папка Claude Code, не трогай без прямого указания
  agents/    zayavki-pdf-to-excel, zayavki-po-menedzheram
  skills/    zayavki (полный цикл)
data/        входящие PDF-заявки (и прочие исходники). Только чтение
docs/        справочные материалы (таблица распределения)
posts/       тексты
promts/      сохранённые промпты
reports/     готовые результаты
  Заявки готовые/         заявки в Excel + Журнал обработки.csv
  Заявки по менеджерам/   подпапка на каждую заявку, внутри файл на каждого менеджера
scripts/     скрипты
tmp/         черновики и промежуточное (рендер страниц — tmp/zayavki_render/, чистится после сборки)
```

# Правила

- Исходные PDF в `data/` и таблица распределения в `docs/` — только чтение. Не менять, не переименовывать, не удалять.
- Все результаты — только в `reports/`. Готовые заявки в `reports/Заявки готовые/` агент разбивки только читает.
- Заявки — сканы без текстового слоя: читаются только через рендер страниц в картинки. Рукописные пометки игнорируются.
- В таблицы переносится только то, что есть в заявке. Пустая ячейка = «в документе не указано». Свои оговорки — на лист «Проблемы» или в отчёт, не в таблицу и не в «Примечание».
- Имена файлов: готовая заявка — `Заявка №<N> от <ДД.ММ.ГГГГ>г. <объект сокращённо>.xlsx`; файл менеджера — `<Фамилия> <Имя>.xlsx`. Файл с тем же именем перезаписывается.
- Позиция не распознана или подходит двум менеджерам — кладётся наиболее вероятному с пометкой «спорно» в колонке «Категория». Каждая позиция — ровно в одном файле, сумма по менеджерам = число позиций в заявке.
- Промежуточное — в `tmp/`, скрипты — в `scripts/`, пользователю не показывать.
- Копии агентов и скиллов вне `.claude/` не держать.

# Отчёт

Итог одной-двумя фразами (сколько новых PDF, заявок, позиций, менеджеров) → таблица по заявкам (заявка / исходный PDF / позиций / менеджеры / сверка), при больше девяти заявок — только папки → спорные места отдельным коротким списком: нечитаемое из листов «Проблемы», спорные позиции (наименование — куда положено — сомнение), пропущенные PDF.
