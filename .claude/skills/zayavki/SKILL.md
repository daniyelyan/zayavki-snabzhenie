Запуск полного цикла по новым заявкам. Пользователь — директор отдела
снабжения, с кодом не работает. Скрипты и техническую сторону не показывай.

# Папки

- `data/` — входящие PDF. Только чтение.
- `reports/Заявки готовые/` — заявки в Excel (шаг 1).
- `reports/Заявки по менеджерам/` — файлы по менеджерам (шаг 2).
- `reports/Заявки готовые/Журнал обработки.csv` — какой PDF в какой xlsx
  превратился. Разделитель `;`, кодировка UTF-8 с BOM (чтобы Excel открыл
  без плясок). Колонки: `PDF;Готовая заявка;Дата обработки`. Нет файла —
  создай с шапкой.

# Порядок

1. **Найти новые PDF.** Все `data/*.pdf`, которых нет в колонке «PDF»
   журнала. Если пользователь при вызове назвал конкретные PDF — бери только
   их (даже если они уже в журнале: значит, нужна повторная обработка).
   Новых нет — одной фразой сообщи и остановись.
2. **Перевод в Excel.** Вызови агента `zayavki-pdf-to-excel`, явно передав
   список новых PDF (полные имена файлов). Всю `data/` ему не отдавай.
3. **Журнал.** По отчёту агента допиши в журнал строки «PDF → готовый xlsx →
   сегодняшняя дата». PDF, которые агент пропустил как не заявки, тоже
   занеси в журнал с пометкой `не заявка` в колонке «Готовая заявка», чтобы
   в следующий раз их не трогать.
4. **Разбивка по менеджерам.** Вызови агента `zayavki-po-menedzheram`,
   явно передав список готовых xlsx, созданных на шаге 2 (полные имена в
   `reports/Заявки готовые/`). Старые заявки не передавай.
5. **Общий отчёт** (см. ниже).

Если шаг 2 по какому-то PDF не дал файла — шаг 4 по нему не запускай, в
журнал не заноси (чтобы при следующем запуске он снова попал в новые), в
отчёте назови.

# Общий отчёт

Один отчёт вместо двух отчётов агентов, без пересказа процесса:

1. Итог одной-двумя фразами: сколько новых PDF, сколько заявок переведено,
   сколько позиций всего, сколько менеджеров задействовано.
2. Таблица по заявкам (если заявок больше девяти — только ссылка на папки):

   | Заявка | Исходный PDF | Позиций | Менеджеры (позиций) | Сверка |

   «Сверка» — «ок», если все позиции заявки разложены, иначе расхождение.
3. Папки с результатом: `reports/Заявки готовые/`,
   `reports/Заявки по менеджерам/`.
4. Отдельным коротким списком: нечитаемые места из листов «Проблемы»,
   спорные позиции по менеджерам (наименование — куда положил — сомнение),
   пропущенные PDF (не заявки / не обработаны).
